# projetos-recomp
Lista organizada com os melhores projetos de recompilação de jogos, além de forks de emulação para jogos específicos (demon's souls remake, por exemplo)
> ⚠️ Nenhum projeto aqui distribui jogos ou assets protegidos. A maioria exige que você tenha sua própria cópia legal do jogo.

## Recompilações

- [Zelda64Recomp](https://github.com/Zelda64Recomp/Zelda64Recomp) - Port de *Majora's Mask* para PC via recompilação estática. `N64` `PC` 🟢

## Decompilações e Ports Nativos

- [Ship of Harkinian](https://github.com/HarbourMasters/Shipwright) - Port de *Ocarina of Time* baseado na decompilação. `N64` `PC` 🟢
- [Starship](https://github.com/HarbourMasters/Starship) - Port de *Star Fox 64*. `N64` `PC` 🟢

## Engines Reimplementadas

- [OpenMW](https://github.com/OpenMW/openmw) - Engine open source para *The Elder Scrolls III: Morrowind*. `PC` 🟢
- [OpenRCT2](https://github.com/OpenRCT2/OpenRCT2) - Reimplementação de *RollerCoaster Tycoon 2*. `PC` 🟢

## Ferramentas

- [N64Recomp](https://github.com/N64Recomp/N64Recomp) - Ferramenta para recompilar jogos de N64 estaticamente. `N64` 🟢

## Emuladores

- [KytyPS5 (fork do chenxiao07)](https://github.com/chenxiao07/KytyPS5) - Emulador de PS5 em C++. Fork do [KytyPS5](https://github.com/KytyPS5/KytyPS5), que deriva do [Kyty](https://github.com/InoriRus/Kyty). Nos meus testes, foi o fork com melhor desempenho em *Demon's Souls* (remake). Atualizado quase diariamente. Requer cópia legal do jogo. `PS5` `Windows` `Linux` `macOS (experimental)` `GPL-2.0` 🟢
